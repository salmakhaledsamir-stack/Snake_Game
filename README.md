🐍 Snake Game

A classic Snake game built with **Python** using the **Turtle graphics library**.

The player controls the snake, collects food to grow longer, and tries to achieve the highest score possible without hitting the walls or the snake's own body.

Features

* 🎮 Keyboard-controlled snake movement
* 🍎 Randomly generated food
* 📈 Score tracking
* 🐍 Snake growth when food is eaten
* 💥 Collision detection with walls and the snake's body
* 🎨 Dynamic food and snake colors

Technologies

* Python
* Turtle Graphics
* Object-Oriented Programming (OOP)

What I Practiced

This project helped me practice **classes and inheritance, object-oriented programming, modules, event handling, collision detection, and managing game state** in Python.

How to Run

1. Clone the repository.
2. Make sure Python is installed.
3. Run `main.py`.
4. Use the arrow keys to control the snake.

Have fun and try to beat your high score! 🐍
